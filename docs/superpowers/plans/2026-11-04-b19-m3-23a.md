# b19-m3-23a: onboarding CLI fixes

**Goal:** close the CLI items that block a first-day developer on WSL2 or Mac and target
M3-23: DF-573 (CSV role import separators), DF-960 (a credential file left after an org ban;
a home on a WSL2 drvfs mount), DF-961 (doctor's keyring probe and the control-plane client
use the injected provider and home), DF-962 (FileStore hardening), DF-963 (Jira
Retry-After as an HTTP date), DF-964 (user-config writer cosmetics), DF-965 (missing CLI
tests). Each fix starts with a test seen failing.

**Architecture:** local changes in the modules that own each behaviour; no new modules.

## Files

- control-plane: `rbac/importer.py` (`parse`); `tests/test_rbac_import.py`.
- core: `auth/filestore.py` (problem guard, owner uid, kept keys, drvfs), `auth/credentials.py`
  (`keyring_only`), `integrations/jira.py` (`_retry_after`); tests under `core/tests/`.
- cli: `credential_store.py` (`forbidden_file_warning`), `commands/login.py`,
  `commands/init.py`, `doctor.py`, `control_plane.py`, `config.py`; tests under `cli/tests/`.
- docs: `docs/guides/developer.md`, `docs/guides/admin.md` (new messages only); records in
  TRACKER.md (M3-23 note) and DEFERRED.md (DF rows).

## Interfaces

- `parse(text)`: the header's separator is sniffed (`csv.Sniffer`, `,;\t` only; comma when
  it cannot tell); trailing empty header cells and the matching empty cells are ignored; an
  unknown column that holds `;`, a tab or `|` adds "separate the columns with commas".
- `FileStore.problem()` never raises: an OSError is a problem with a fix; on POSIX a file
  owned by another uid is refused; a file too open on a drvfs mount names `AGENTIC_HOME`.
  `check_writable()` refuses a folder where a new 0600 file reads wider. `_write` keeps
  top-level keys it does not understand. `drvfs_mount(path, mounts)` reads /proc/mounts.
- `Credentials.keyring_only()`: the same environment, keyring and service, no file.
- `forbidden_file_warning(env, home) -> str | None`, shown once by `login` and `init`.
- `_retry_after` accepts an HTTP date (seconds from now, rounded up, never negative).
- `ConfigChange.added`: the keys appended; a replaced null is a change. Rows split on `\n`
  only, each keeps its line ending; appended rows use the file's majority ending.

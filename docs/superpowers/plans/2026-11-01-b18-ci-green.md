## Root causes (from runs 41369404769, 41369354921, 41267736902)

| Failure | OS | Root cause | Fix |
|---|---|---|---|
| `test_helm_chart.py`, `test_helm_environments.py` (76) | Windows | `docker` is on PATH but its daemon is not running (or runs Windows containers); `docker run` then exits 1, not 125, so no skip | `helm_support.tools()` asks the engine whether it can run Linux containers (`info`) before use; skips with the reason otherwise |
| `test_eval_devtask.py` (4, also nightly) | macOS | `$TMPDIR` is `/var/...`, a symlink to `/private/var/...`; pytest's `--rootdir` got the unresolved path while its cwd (from `getcwd`) is the resolved one, so node ids are not `tests/...` and every outcome reads as failed | `run_tests` resolves the folder first |
| `test_tools.py::test_read_refuses_an_absolute_path_outside` | macOS | the test's leak sentinel is the word `private`, which is in macOS's tmp path (`/private/var`) the agent itself supplied; the refusal echoes only the agent's own argument | sentinel content that cannot appear in a path |
| process-tree kill tests (5) | macOS | the test helper `alive()` reads `/proc` for the zombie state; without `/proc` it uses `kill(pid, 0)`, which succeeds for a killed but unreaped zombie | `alive()` asks `ps` for the state where there is no `/proc`; the kill code is right |
| `test_notify_delivery.py` (2) | macOS | aiosmtpd's `SMTP()` calls `socket.getfqdn()` (slow reverse DNS on macOS runners) inside the 1 s `ready_timeout` | capture relay passes a fixed `server_hostname` and a longer `ready_timeout` |
| `OSError: AF_UNIX path too long` (warning) | macOS | the sandbox probe binds its Unix socket inside the work folder, past macOS's 104-byte limit; the thread died and the "unix socket" case read as blocked whatever the sandbox did | bind in a short temporary folder, synchronously, so a failure is loud |

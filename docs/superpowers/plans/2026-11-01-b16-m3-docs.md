# b16-m3-docs (M3-18): the guides and the command reference

**Goal:** one short guide per reader (developer, team lead, admin, auditor, policy repo),
a root README, a runbooks index and a command reference that lists every `agentic` and
every `python -m agentic_cp` command, with tests that fail when a command has no entry or
an entry names a command that does not exist. Close or retarget the ten DF items that
target M3-18.

**Ground truth:** the Typer app (`agentic_cli.main.build_app`) and the argparse parser
(`agentic_cp.__main__.build_parser`), not the plan. Audience and tasks from spec §23–§27
and the master plan's "Users and roles" and "Developer onboarding".

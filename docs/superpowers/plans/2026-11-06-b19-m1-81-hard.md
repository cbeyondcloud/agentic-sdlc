## Interfaces

- `agentic.transport.retry_after.retry_after_seconds(value: str | None, *, longest=86400.0,
  now: datetime | None = None) -> float | None`: delta-seconds or an HTTP date, never
  negative, capped at `longest`; None when absent or unreadable (OverflowError included).
  `MAX_RETRY_AFTER` moves there (nothing imported Jira's copy, so it is not re-exported).
- `CassetteServer.start(port: int = 0)`: 0 keeps the OS-chosen port. On Windows the
  socket is bound without SO_REUSEADDR (which there lets a second socket share a busy port).
- `agentic training-gateway --port N` (1..65535): a busy or reserved port exits 1
  (ERROR: the flag is right, the machine is not ready) naming the port and the fix; a
  port out of range is a usage error (64).

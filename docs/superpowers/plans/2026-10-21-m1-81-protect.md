> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close or re-home every Open DEFERRED.md item that targets M1-81 and was found in the protection-layer sub-plans (SP8 sandbox, SP9 code intelligence, SP10 skills, SP12 telemetry/AGENTS.md, P0-03 supply chain, S12 container runtime). Each item is re-graded by its effect on a Windows or macOS developer in a 1000-person org: fixed test-first when it can cause wrong behaviour, a safety gap, a confusing failure or a cross-platform break; accepted with a reason when cosmetic; retargeted to the M2/M3 row that owns it.

**Spec:** `docs/superpowers/specs/2026-10-16-agentic-sdlc-design.md` §9 (sandbox), §10.4 (AGENTS.md), §11.3 (skill admission), §15 (untrusted content), §16 (supply chain). Tracker row M1-81.

## Global Constraints

- Stay inside the protection-layer files listed above; engine, definitions and CLI command files belong to other hardening tracks.
- Windows and macOS behave the same; any path test runs on both (no POSIX-only assumptions, no `os.sep` literals in expectations).
- Never add `# fmt: skip` / `# fmt: off`; ruff line length 100.
- Fake secrets in tests are built from pieces (gitleaks runs in the Linux stage).
- TRACKER.md, DEFERRED.md and DECISIONS files are not edited here; outcomes go in the track's structured output.
- `uv run python scripts/check.py --all` green on Windows and Linux.

## Review Focus

1. **A secret in an oddly named variable or inside a URL never reaches an agent command** (`GITHUB_PAT`, `SSH_AUTH_SOCK`, `DATABASE_URL=postgres://u:p@h/db`), while `PATH`, `HOME`, `GIT_AUTHOR_NAME`, `PATHEXT` and `SYSTEMROOT` still do. Test: Task 1.
2. **An agent-made program cannot borrow an allow rule**: `./pytest`, `/tmp/x/git status`, `bin\pytest.cmd` are not covered by `pytest` / `git status`, and on Windows `cmd.exe` no longer runs a same-named file from the working folder. Test: Task 2.
3. **The sandbox settings file is never writable from inside the sandbox.** Test: Task 3.
4. **A corrupt or half-built code index heals itself**, two parallel tool calls build once, and the code-review-graph subprocess never sees a secret. Test: Task 4.
5. **`impact(diff)` finds the files of real-world diffs**: quoted non-ASCII names, pure renames, `--no-prefix`, `diff -u` timestamps. Test: Task 5.
6. **Agent text in the PR body is inert**: a proposed AGENTS.md addition cannot render an image, a link or an @mention, and the list is bounded. Test: Task 6.
7. **A just-published transitive package cannot enter the lock** (uv `exclude-newer`), and an offline developer can run the checks that need no network, clearly labelled incomplete. Test: Task 8, Task 9.

# b20-cp-pilot: held-back runs and the git host allow-list

> Track b20-cp-pilot. Two owner decisions settled 2026-11-07 (not re-opened here).
> DF range DF-1018 to DF-1024.

**Goal.**
1. DF-536: a run the publish scan holds back is closed out on the control plane with a
   terminal `held_back` marker that carries only the finding kinds, and `agentic sync` stops
   failing for it. An admin can still redact locally and publish the rest later.
2. DF-484 + DF-503 (+ DF-798, the same remainder): the control plane fetches git only from
   hosts the org policy allows, and refuses a host that resolves to a private, loopback,
   link-local, unspecified, multicast or reserved address unless that host is listed
   explicitly. Checked at registration and again at every fetch. git's own error line is
   logged, never returned.

**Architecture.**
- Held back: `POST /v1/runs/{run_id}/held-back` with `HeldBackRequest{seq, kinds}`. `seq`
  must be the event right after the stored head (the chain is not skipped), `kinds` are
  id-shaped finding kinds (never values). The run becomes `held_back` (not `open`, so it
  holds no concurrency slot, is never stale and is not counted as running), and the tenant's
  chain gets `run.held_back`. The same marker again is a no-op. Ingest stays open: entries
  re-chained after a local redaction verify from the head as any batch does, the run goes
  back to `open` (or the `run_closed` status) and `run.republished` is audited. The CLI's
  run sink posts the marker after sending the clean entries; `agentic sync` then reports the
  run as held back without an error and exits 0. If the marker cannot be delivered the old
  error stays.
- Git hosts: `org.yaml: allowed_git_hosts` (optional list of host names or IP literals,
  exact match, case-insensitive). The accepted version stores it in its settings
  (`git_hosts`). `GitHosts(explicit, implicit)` is the tenant's effective list:
  - set: every listed host is explicit; a policy that does not list its own policy repo's
    host is rejected (it could never sync again).
  - absent (default, backward compatible): explicit = the policy repo's host (set by an org
    admin); implicit = `github.com` plus the hosts of repos already registered. Implicit
    hosts must resolve to public addresses only.
  `gitops.check_git_host(url, hosts, resolve=...)` raises `RepoUrlError` with a generic
  message. Called by `PUT /v1/tenant/policy-source`, `POST /v1/repos`, the policy fetch and
  the CODEOWNERS refresh. `GitError.reason` is the caller-safe text; the raw line is logged.

**Interfaces.**
- `HeldBackRequest(seq: int >= 1, kinds: list[Kind] 1..32)`, `HeldBackResult(status, head,
  duplicate)`.
- `ControlPlaneClient.hold_back(run_id, seq, kinds) -> HeldBackResult`.
- `GitHosts(explicit: frozenset[str], implicit: frozenset[str])`,
  `check_git_host(url, hosts, *, resolve)`, `async tenant_git_hosts(conn, tenant)`.

**Review focus.** A marker must not move the head or let a client skip events; kinds can
carry no value. The host check runs before every git fetch (DNS can change). Defaults keep
an existing install working.

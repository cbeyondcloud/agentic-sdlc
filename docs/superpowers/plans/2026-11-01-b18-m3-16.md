## OSS reuse

| Need | Reused | Not reused, why |
|---|---|---|
| Before/after run of one case | `agentic.learning.regression.measure` over `run_eval` (pydantic-evals, MIT) with `AgentCaseRunner` and `evaluation.with_skill` (the M2-46 overlay) | a second runner or a judge model: the lesson-coverage score is deterministic |
| Model calls in tests | the CLI's `runtime.network_transport` seam and `FakeGateway` (the run tests' model path) | any live provider (owner decision 73) |
| Run ledger | `EvalLedger` (Zyroflo's hash chain via commons) | a new ledger |
| Policy-repo PR | `skill_promotion.policy_checkout`, `repo_setup.commit_on_branch`, `hosting.connect`, `HostingProvider.open_pull_request`, `authoring.catalog_entry`/`skill_sha` | PyGithub (LGPL) |
| Closing a PR | a new optional `ClosingHost` protocol beside `ReviewHost`; GitHub `PATCH pulls/{n}` | widening `HostingProvider` (every adapter would have to close) |

# b19-m3-23b: the onboarding kit (M3-23)

**Goal.** Everything up to the pilot measurement of M3-23: a docs site built from `docs/`,
one sample repo for training, a 30-minute training deck, an office-hours plan, a no-spend
training gateway for the walkthrough's real run, and an offline onboarding timer with a
facilitator sheet. The pilot itself (5 developers, median 15 minutes or less) is the
owner's; M3-23 stays In progress until it is measured.

## Choices (OSS first)

| Need | Looked at | Chosen | Why |
|---|---|---|---|
| Docs site generator | Material for MkDocs 9.x (MIT; final maintenance period ends 2026-11-05, features now go to Zensical); Zensical 0.0.x (MIT; alpha, reads `mkdocs.yml`); MkDocs 2.0 (pre-release, no migration path, no plugins); Sphinx + MyST (BSD/MIT; docutils' mixed licence metadata, heavier); MkDocs 1.6.1 (BSD-2, stable) | **MkDocs 1.6.1 with its built-in theme** | Stable and pure Python; `--strict` with `validation:` fails on broken links and anchors; the built-in theme ships its CSS, JS and fonts locally, so the site needs no CDN or font host and has no analytics. The same `mkdocs.yml` is what Zensical builds, so moving later is a config change, not a rewrite. Material is not used: its maintenance ends this week. |
| Slides | Marp (MIT), reveal.js (MIT), Slidev (MIT) | **Marp Markdown** (`marp: true` front matter, `---` between slides) | Plain Markdown that reads fine unrendered; rendering is optional (`npx @marp-team/marp-cli`). |
| Fake gateway for the training run | the cassette server `agentic.eval.replay` (already shipped, M1-63) | **reuse it**: `agentic training-gateway` replays one recorded cassette | No new server code; the recording is an acceptance scenario, so it cannot drift from the CLI. |
| Onboarding timestamps | init's audit log (`.agentic/local/audit/init-events.jsonl`), `init.json`, run ledgers, the credential store | **a small local `~/.agentic/onboarding.json`** written at the four first milestones | Login and a dry run leave no local timestamp today (the keyring has none; a dry run writes nothing). The file holds four pairs of times only, is written at most until the first dry run passes, never leaves the machine, and is not written in CI. |

MkDocs pulls `pathspec` (MPL-2.0, unmodified): a licence exception like certifi's, flagged
for the owner. The docs group is optional (`uv sync --group docs`), so nothing reaches the
CLI wheel.

## Interfaces

- `agentic onboarding [--reset]`: first `login` attempt to first successful
  `run --dry-run`, and each step's time. `--json` gives `{complete, total_seconds, steps}`.
- `agentic training-gateway`: serves the bundled training cassette on 127.0.0.1 until
  Ctrl-C and prints the `AGENTIC_GATEWAY_URL` to set. Replay only: no model, no network.
- `onboarding.note(args, code, started, finished)`: called by `main`, never raises.
